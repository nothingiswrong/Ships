
# Проверка корректности растановки кораблей на поле игры «Морской бой».

1. Загрузка поля из файла (`10x10`), где:
   - `0` — пустая клетка
   - `*` — часть корабля
2. Проверка корректности расстановки кораблей:
   - 1 корабль длиной 4
   - 2 корабля длиной 3
   - 3 корабля длиной 2
   - 4 корабля длиной 1
   - корабли не должны соприкасаться (включая диагонали)
3. Показывает результат:
   - поле корректно / некорректно
   - подсветка ошибочных клеток
   - панель с текстовыми ошибками рядом с полем
